# User API - Test Cases

| ID           | Test Scenario             | Test Objective                                            |
| ------------ | ------------------------- | --------------------------------------------------------- |
| USER-API-001 | GET existing user         | Verify successful retrieval of an existing user           |
| USER-API-002 | GET nonexistent user      | Verify behavior when the requested user does not exist    |
| USER-API-003 | POST valid user data      | Verify the API response when submitting user data         |
| USER-API-004 | POST incomplete user data | Observe API behavior when required information is missing |

## Notes

The exercise did not include a complete formal API specification defining all expected validation rules.

Therefore, some behavior may require further specification review before a definitive pass or fail decision can be made.
