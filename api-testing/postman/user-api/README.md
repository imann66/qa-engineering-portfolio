# User API Testing

## Overview

This project contains API testing exercises using the JSONPlaceholder practice API.

The objective is to understand REST API behavior, validate response data, and test positive and negative request scenarios.

## Test Scope

- Retrieve an existing user.
- Retrieve a nonexistent user.
- Submit a POST request to create a user.
- Submit a POST request with incomplete data.

## Tools

- Postman
- REST API
- HTTP
- JSON
- JSONPlaceholder

## Notes

JSONPlaceholder is a simulated practice API. Successful POST responses should not be interpreted as proof of permanent database persistence.

Refer to `test-cases.md` and `execution-report.md` for the test scenarios and recorded outcomes.
