# BUG-001 – Last Name Field Affects First Name During Checkout

| Severity     | High                                               |
| Priority     | High                                               |
| Status       | Reported                                           |
| Testing Type | Manual Exploratory Testing                         |

## 2. Description

During exploratory testing, an issue was identified in the checkout process using the `problem_user` account.

The Last Name field affected the First Name field, resulting in unexpected form behavior and preventing the checkout process from proceeding successfully.

## 3. Preconditions

- Sauce Demo is accessible.
- The tester has valid access to the `problem_user` account.
- The user can access the product inventory and shopping cart.

## 4. Steps to Reproduce

1. Open https://www.saucedemo.com/.
2. Log in using the `problem_user` account.
3. Add a product to the shopping cart.
4. Navigate to the shopping cart.
5. Proceed to checkout.
6. Enter the required customer information.
7. Observe the behavior of the First Name and Last Name fields.
8. Attempt to continue the checkout process.

## 5. Expected Result

- The First Name field should retain its own entered value.
- The Last Name field should retain its own entered value.
- Entering information in one field should not unexpectedly modify another field.
- The checkout process should proceed when all required information is valid.

## 6. Actual Result

- The Last Name field affected the First Name field.
- The checkout form did not behave as expected.
- The checkout process was blocked.

## 7. Impact Assessment

**Severity: High**

The issue affects the checkout workflow and prevents the user from completing the purchase process under the tested conditions.

**Priority: High**

The defect affects a critical business workflow and should be investigated with high priority.
